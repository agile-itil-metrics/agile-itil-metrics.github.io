# 模板

四份可复制和改编的模板：指标章程、指标卡、仪表板规格和评审议程。它们是起点。替换方括号中的文字，删去不适合的内容，并尽可能让每份文档保持在一页。

## 指标章程

```text
[团队、服务或组织]的指标章程

目的
我们度量[服务和工作方式]，以便[改进…… / 看到…… / 决定……]。
这些度量帮助我们看到自己的工作并加以改进。它们不是评判个人的办法。

数据用来做什么
- 团队评审工作进展如何，以及接下来尝试什么。
- 关于在服务、工具和技能上在哪里投资的决定。
- [监管者/客户]要求的报告：[列表，保持分开]。

数据绝不用来做什么
- 给个人排名或比较个人。
- 个人绩效评审、薪酬、晋升或解雇。
- [添加你的团队提出的担忧。]

谁看到什么
- 每个团队先看到自己的数据，并拥有解读。
- [角色]看到汇总的服务和团队趋势。
- 个人层面的视图在[工具]中关闭。

保留的数据
- [收集什么、来自哪些系统、保留多久。]

质疑
- 任何人都可以质疑一个数字。我们在[数量]个工作日内回应。
- 联系人：[姓名或小组]。

违反
- 向[途径]报告任何违背本章程的使用。结果在不指名的情况下公布。

评审
- 我们每[六个月]与团队一起评审本章程。

签署：[发起人]、[团队代表]   日期：[日期]
```

## 指标卡

```text
指标卡：[指标名称]

它回答的问题：[受众提出的问题]
它为之提供信息的决定：[有人可能因此做出的不同做法]
定义：[平实的话]
公式：[如何计算]
单位：[单位]   频率：[多久一次]
时钟或边界规则：[何时开始计数、停止、暂停]
数据来源：[系统和字段]   刷新：[间隔]
负责人：[角色]   可询问的人：[姓名或小组]
受众：[团队、服务负责人、领导层]
层面：[团队、服务或系统。绝不是个人。]
展示：[中位数和百分位数、运行图、分布]
基线：[期间，以及来自我们自己数据的数值]
已知局限：[缺口、录入习惯的变化、样本量]
操纵途径：[如何在没有变好的情况下看起来变好]
护栏：[配对的指标或实践]
伙伴成果：[应与之一起阅读的成果]
相关主题：（见主题 [N.M]，[标题]）
退役条件：[条件]
上次评审：[日期]   自上次评审以来的变化：[备注]
```

## 评审议程

一次 45 分钟的团队评审，每月或每季度进行。这是一场关于工作的交谈，由团队主导。

```text
[团队]的指标评审，[日期]

1. 近况交流（5 分钟）
   工作进展如何？有什么是数字不会显示的？

2. 自上次以来的事件（5 分钟）
   发布、事件、人员变动、政策变更。在展示中添加说明。

3. 趋势与分布（15 分钟）
   对每项度量：我们看到了什么？这是普通变异还是信号？
   把每项度量与其护栏一起阅读。检查数据新鲜度和已知缺口。

4. 决定（10 分钟）
   我们将尝试、停止或改变什么？记录每项决定，包括观望的
   决定。指名负责人和再次查看的日期。

5. 上次的决定（5 分钟）
   上次的决定有帮助吗？我们学到了什么？

6. 度量本身（5 分钟）
   哪项度量让我们困惑或误导了我们？哪些可以退役？缺少什么？

记录：决定、负责人、日期、对度量的改变。
规则：不比较个人。数字描述的是系统。
```
