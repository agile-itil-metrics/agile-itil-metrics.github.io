# รายการตรวจสอบ

รายการตรวจสอบสามชุดสำหรับทีมโปรแกรม ได้แก่ ชุดสำหรับทบทวนตัวชี้วัดเดี่ยว ชุดสำหรับเปิดใช้แดชบอร์ด และชุดสำหรับตรวจสอบโปรแกรมตัวชี้วัด ใช้เป็นหัวข้อกระตุ้นการสนทนากับทีม ไม่ใช่แบบฟอร์มที่กรอกแล้วเก็บเข้าแฟ้ม ปรับให้เหมาะสม และตัดรายการที่ไม่เข้ากับบริบทของท่านออกได้

## รายการตรวจสอบการทบทวนตัวชี้วัด

ใช้ก่อนนำตัวชี้วัดไปใช้ และในการทบทวนตามรอบทุกครั้ง (ดูหัวข้อ 1.4 “การกำกับดูแลและความเป็นเจ้าของตัวชี้วัด”)

**วัตถุประสงค์**

- [ ] ตัวชี้วัดตอบคำถามที่กลุ่มผู้ชมที่ระบุไว้เป็นผู้ถาม
- [ ] บันทึกการตัดสินใจที่ตัวชี้วัดควรให้ข้อมูลไว้เป็นลายลักษณ์อักษรแล้ว
- [ ] ตัวชี้วัดวัดผลลัพธ์ หรือจับคู่กับผลลัพธ์อย่างชัดเจน (ดูหัวข้อ 1.3 “ผลลัพธ์สำคัญกว่าผลผลิต: การเลือกสิ่งที่จะวัด”)

**นิยาม**

- [ ] มีนิยาม สูตร หน่วย และแหล่งข้อมูลเป็นลายลักษณ์อักษร
- [ ] กฎของนาฬิกาหรือขอบเขตชัดเจน (เริ่มนับ หยุดนับ และพักการนับเมื่อใด)
- [ ] ระบุชื่อเจ้าของ และบุคคลที่ควรสอบถามเมื่อตัวเลขดูผิดปกติ
- [ ] บันทึกข้อจำกัดที่ทราบของข้อมูลไว้แล้ว รวมถึงช่องว่างและการเปลี่ยนแปลงวิธีการบันทึก

**ความซื่อตรง**

- [ ] บันทึกช่องทางการบิดเบือนที่มีแนวโน้มมากที่สุดไว้แล้ว
- [ ] มีตัวชี้วัดหรือแนวปฏิบัติมาตรการป้องกันที่จับคู่กันไว้
- [ ] ตัวชี้วัดอธิบายทีม บริการ หรือระบบ และไม่จัดอันดับบุคคล
- [ ] ตัวชี้วัดด้านเวลาแสดงมัธยฐานและเปอร์เซ็นไทล์ระดับสูง พร้อมขนาดตัวอย่าง (ดูหัวข้อ 1.6 “ความรู้ด้านสถิติสำหรับตัวชี้วัดบริการ”)
- [ ] มีค่าฐานจากหลายช่วงเวลา เพื่อให้อ่านการเปลี่ยนแปลงเทียบกับความแปรปรวนตามปกติได้

**การใช้งาน**

- [ ] ทีมที่ทำงานเห็นตัวเลขก่อน และมีส่วนร่วมในการกำหนดนิยาม
- [ ] การทบทวนครั้งล่าสุดนำไปสู่การตัดสินใจที่บันทึกไว้ รวมถึงการตัดสินใจที่จะรอ
- [ ] บันทึกเงื่อนไขการเลิกใช้ตัวชี้วัดไว้เป็นลายลักษณ์อักษรแล้ว

## รายการตรวจสอบการเปิดใช้แดชบอร์ด

ใช้ก่อนแสดงแดชบอร์ดต่อกลุ่มผู้ชม (ดูหัวข้อ 11.1 “การออกแบบแดชบอร์ดตัวชี้วัดบริการ”)

**กลุ่มผู้ชมและเนื้อหา**

- [ ] บันทึกกลุ่มผู้ชมและคำถามของกลุ่มไว้แล้ว และกลุ่มผู้ชมมีส่วนช่วยทบทวนภาพร่าง
- [ ] มุมมองนี้มีตัวชี้วัดไม่เกินประมาณเก้าตัว โดยรายละเอียดอยู่ลึกลงไปหนึ่งขั้น
- [ ] ชุดตัวชี้วัดสมดุลทั้งการไหลของงาน คุณภาพ ความน่าเชื่อถือ ประสบการณ์ และต้นทุน
- [ ] ทุกตัวชี้วัดมีตัวคู่ที่ช่วยป้องกันการบิดเบือนที่มีแนวโน้มจะเกิดขึ้น

**ความชัดเจน**

- [ ] ทุกค่าแสดงแนวโน้มและบริบท พร้อมบันทึกเหตุการณ์
- [ ] ทุกตัวชี้วัดมีนิยาม แหล่งข้อมูล เจ้าของ เวลาที่รีเฟรช และช่องว่างที่ทราบ ภายในหนึ่งคลิก
- [ ] เป้าหมายแสดงเป็นเส้นอ้างอิง และสีสถานะใด ๆ เป็นไปตามกฎที่ระบุไว้ซึ่งคำนึงถึงความแปรปรวน
- [ ] ตัดสิ่งตกแต่งที่ไม่ได้เพิ่มข้อมูลออกแล้ว

**ความไว้วางใจและการดำเนินงาน**

- [ ] ได้ตกลงกฎบัตรแล้ว และปิดมุมมองระดับบุคคล (ดูหัวข้อ 11.3 “เริ่มใช้ตัวชี้วัดโดยไม่สร้างความหวาดกลัว”)
- [ ] ทีมได้เห็นข้อมูลของตนเอง และมีเวลาแก้ไขให้ถูกต้อง
- [ ] ดึงข้อมูลโดยอัตโนมัติ พร้อมการตรวจสอบความสดใหม่และการกระทบยอดกับแหล่งข้อมูล (ดูหัวข้อ 11.2 “ภาพรวมเครื่องมือ”)
- [ ] มีเจ้าของที่ระบุชื่อ วันทบทวน และช่องทางการโต้แย้ง
- [ ] รายงานที่แดชบอร์ดนี้มาแทนที่มีวันเลิกใช้

## รายการตรวจสอบการตรวจสอบโปรแกรม

ใช้ปีละสองครั้ง ร่วมกับทีม พร้อมกับการประเมินด้วยตนเอง (ดูหัวข้อ 12.5 “การประเมินวุฒิภาวะด้วยตนเอง”)

**วัตถุประสงค์และความไว้วางใจ**

- [ ] โปรแกรมมีผู้สนับสนุนและกฎบัตรเป็นลายลักษณ์อักษรที่ผู้นำปฏิบัติตาม
- [ ] การละเมิดกฎบัตรที่มีการรายงานได้รับการจัดการ และเผยแพร่ผลโดยไม่ระบุชื่อ
- [ ] แบบสำรวจทีมและรายงานเหตุเฉียดอุบัติเหตุไม่บ่งชี้ว่าความหวาดกลัวเพิ่มขึ้น
- [ ] ไม่มีตารางจัดอันดับของทีมหรือบุคคลอยู่ที่ใดในเครื่องมือหรือสไลด์ขององค์กร

**ตัวชี้วัดและข้อมูล**

- [ ] แต่ละทีมระบุได้ว่าตัวชี้วัดของตนให้ข้อมูลแก่การตัดสินใจใดบ้างในไตรมาสที่แล้ว
- [ ] เก็บนิยามไว้ในแคตตาล็อกที่พกพาได้ พร้อมเจ้าของ
- [ ] ตรวจสอบความครอบคลุมของแหล่งข้อมูล ความน่าเชื่อถือของไปป์ไลน์ และการกระทบยอด และมองเห็นได้
- [ ] ได้ทดสอบการส่งออกนิยามและประวัติในช่วงหนึ่งปีที่ผ่านมา

**ความสมดุลและความกว้าง**

- [ ] ตัวชี้วัดผลลัพธ์อยู่ข้างตัวชี้วัดกิจกรรมในแต่ละมุมมอง
- [ ] ตัวชี้วัดที่เกี่ยวกับปัญญาประดิษฐ์ใช้ค่าฐาน การสุ่มตัวอย่าง และผลลัพธ์ที่ได้รับการยืนยัน ไม่ใช่ดูแต่ปริมาณ (ดูหัวข้อ 10.4 “เงินเฟ้อของตัวชี้วัดและคุณภาพที่เจือจาง”)
- [ ] ตัวชี้วัดด้านต้นทุน ความเสี่ยง และบุคลากรมีอยู่ในจุดที่สำคัญ และไม่มีตัวใดใช้จัดอันดับบุคคล

**การปรับปรุง**

- [ ] การดำเนินการปรับปรุงจากการทบทวนครั้งล่าสุดเสร็จสิ้น หรือยกเลิกพร้อมเหตุผล
- [ ] มีการเลิกใช้ตัวชี้วัดและรายงานในช่วงหนึ่งปีที่ผ่านมา
- [ ] ประเมินแรงที่ขอจากทีมสำหรับการวัดแล้ว และทีมยอมรับได้
- [ ] ทบทวนตัวโปรแกรมเองร่วมกับทีมแล้ว และแผนถูกเปลี่ยนตามผลนั้น (ดูหัวข้อ 11.5 “แผนที่นำทางการนำไปใช้แบบค่อยเป็นค่อยไป”)
